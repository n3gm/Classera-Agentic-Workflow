# Classera Agentic Workflow (Auto-Muallimah) 🤖📚

## 📌 عن المشروع (About the Project)
نظام ذكاء اصطناعي متكامل يعتمد على معمارية الوكلاء المتعددين (Multi-Agent Workflow) لتخفيف العبء التشغيلي عن المعلمين. يقوم النظام بأتمتة دورة تحضير الدروس بالكامل، بدءاً من قراءة المناهج الدراسية، مروراً بتوليد أوراق العمل والتحضير الشفهي، وانتهاءً برفع ونشر المحتوى تلقائياً على نظام إدارة التعلم (Classera LMS). 

تم تصميم النظام خصيصاً للتعامل مع مناهج التاريخ، الجغرافيا، والمواد الإدارية للمراحل الدراسية من الصف الرابع الابتدائي وحتى الأول الثانوي، مع ضمان الالتزام التام بالنص الدقيق للمنهج باستخدام تقنيات استرجاع المعلومات (RAG).

## ✨ المميزات الرئيسية (Key Features)
* المعرفة الموجهة (RAG Pipeline): استخراج المعلومات حصرياً من ملفات الـ PDF الخاصة بالمناهج السعودية المحلية لمنع "الهلوسة" وضمان دقة المحتوى.
* الوكيل التربوي (Educator Agent): صياغة أهداف الدرس، استراتيجيات الشرح، وتوليد أوراق عمل (اختيارات، صح/خطأ، تفكير ناقد) مخصصة لكل مرحلة عمرية.
* وكيل التحضير الشفهي (Instructor Agent): إعداد سيناريو تفصيلي للحصة يشمل مقدمة مشوقة وأسئلة للنقاش الصفي.
* أتمتة النشر (Classera Deployment Automation): سكربت يعمل في الخلفية لتسجيل الدخول، رفع عروض الباوربوينت وأوراق العمل، ونشرها آلياً للفصول المحددة على منصة Classera دون أي تدخل يدوي.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* لغة البرمجة: Python
* هندسة الوكلاء: LangGraph / CrewAI
* استرجاع المعلومات (RAG): LangChain, ChromaDB (Vector Database)
* معالجة الملفات: PyPDFLoader, RecursiveCharacterTextSplitter
* أتمتة الويب (Web Automation): Playwright

## 🏗️ هيكلية النظام (Architecture)
1. Data Ingestion: تقطيع نصوص المناهج وتحويلها إلى متجهات (Embeddings) وتخزينها محلياً.
2. Task Delegation: استلام موضوع الدرس وتوجيهه لوكلاء الذكاء الاصطناعي لاستخراج المادة العلمية وصياغتها.
3. Automated Deployment: تشغيل متصفح مخفي (Headless Browser) لرفع المخرجات النهائية إلى منصة Classera.
